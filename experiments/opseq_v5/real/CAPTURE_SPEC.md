# iPhone 拍摄规范 — 拓扑重建专用（一次拍对）

依据 §8 survey 的四类失败（partial orbit / SAM2 跟踪失败 / 把手孔被填 / 场景式拍摄），
按此规范拍一条即可得到第一个真实 genus-1 结果。App：**StrayScanner**（要 LiDAR 机型）。

## 硬性要求（每一条都对应一个已发生的失败）

1. **单物体、素背景**：物体放在纯色（最好白/灰）桌面或转盘上，背景无杂物。
   ← 6c96741473 失败：暗色小物 + 杂乱背景，SAM2 IoU 0.16。
2. **物体方位角 360° 全覆盖**：绕物体走完整一圈（脚走一圈，不是手晃一圈）。
   相机路径全环 ≠ 物体方位全覆盖——每一帧物体都要在画面中央。
   ← e7da89a9bb(220°)、1bea72bf80(151°) 失败：壳成月牙/楔形。
3. **两个仰角各一圈**：一圈平视（物体高度），一圈俯视 ~30-40°。
   ← 单仰角时顶部/底部无约束，壳上下发散。
4. **马克杯必须空杯**，把手朝外、全程可见，绕圈时透过把手孔能看到背景的帧要占多数。
   ← bb126f8e17 失败：把手孔在剪影里被填死（genus 0）或误开 1670 个孔。
5. **距离 30-50 cm**，物体占画面 1/3-1/2；慢速匀速（一圈 ≥ 40 秒），避免运动模糊。
6. **光照均匀**，避免强背光/镜面反光（SAM2 和剪影都吃亏）。

## 建议拍摄清单（每条 1-2 分钟）

| # | 物体 | 期望 genus | 验证点 |
|---|------|-----------|--------|
| 1 | 空马克杯（把手明显） | 1 | 真实数据首个正确亏格发现 |
| 2 | 甜甜圈/游泳圈玩具 | 1 | 大孔、无歧义 |
| 3 | 剪刀（闭合） | 2 | 双孔 |
| 4 | 任意 genus-0 物体（瓶/杯无把手） | 0 | 阴性对照 |

## 拍完之后（Hani 侧一条命令）

```
bash real/prep_object.sh <capture_id>     # 帧抽取 + ARKit→COLMAP + rembg + SAM2-video
python3 real/carve_object.py <capture_id> # 壳雕刻 + 亏格 oracle
# 然后走 golden_chain（v6.3）
```
ARKit 位姿转换与 SAM2 双种子分割已就绪（ray-miss 4-8 mm，瓶身 IoU 0.99）。
